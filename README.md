# SkyForge Flight Simulator

전 세계 실제 지형·위성영상 위에서 비행하는 **전문가용(하드코어) 비행 시뮬레이터**입니다.
게임 엔진(Unity/Unreal) 대신 **자체 비행역학 엔진 + CesiumJS 지구 렌더러 + three.js 3D 조종석**으로 만들었고,
브라우저에서 바로 실행됩니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 비행역학 회귀 테스트 (전 기종 이륙·트림·오토파일럿)
npm run build      # dist/ 정적 빌드 (GitHub Pages 배포 워크플로 포함)
npm run navdata    # 공항·활주로·항행시설 DB 재생성 (OurAirports)
```

## 주요 기능

| 영역 | 내용 |
|---|---|
| 월드 | 지구 전체. Esri 위성영상 + SRTM 30 m 지형 (키 불필요). Cesium ion 토큰 입력 시 **Bing 항공사진(MSFS와 같은 소스)**, Cesium World Terrain, **Google Photorealistic 3D Tiles**, OSM 3D 건물. 공항 활주로 지형 평탄화, 실시간 태양·대기·야간, 안개/시정, 적운 구름층 |
| 공항 | OurAirports 기반 **공항 36,197개 · 활주로 41,769개 · VOR/NDB 11,008개**. 지구본에서 공항을 클릭해 출발/도착 선택. 활주로·접근등(ALS)·PAPI(실제 각도에 따라 색 변화)·엣지등 |
| 기종 | 50종: C152/C172(G1000·아날로그)/J-3/XCub/Arrow/DR400/DA40/SR22/Bonanza/Extra 330/ICON A5/Beaver/P-51/DC-3/Baron/DA62/Caravan/Kodiak/TBM 930/PC-12/King Air/Twin Otter/ATR 72/Q400/Vision Jet/HondaJet/CJ4/Longitude/G650/CRJ700/E175/A320neo/A321neo/737-800/737 MAX 8/A310/A330neo/A350/A380/747-8/777-300ER/787-9/Concorde/F/A-18E/F-16C/글라이더 2종/헬리콥터 4종 |
| 비행역학 | 6자유도 강체, WGS-84 위 NED 적분(120 Hz), 비선형 양력·실속·스핀(자동회전), 압축성·초음속 조파항력, 지면효과, 스프링-댐퍼 착륙장치(브레이크·스티어링·테일드래거), 엔진별 모델(피스톤 믹스처/터보차저, 터보프롭, 터보팬 스풀, 애프터버너, 역추력), 헬기 로터(운동량 이론·ETL·거버너·토크·자동회전·VRS), 난기류/돌풍/풍속 시어. 각 기종의 공개 실속속도·순항점으로 공력계수를 도출 |
| 조종계통 | Airbus 노멀 로(G 명령·받음각/뱅크/피치 보호·플레어 로), 전투기 FBW, 요 댐퍼, AP/FD(HDG·LNAV·LOC·APPR/GS·ALT·V/S·FLC), 오토스로틀·알파플로어, **오토랜드(FLARE/RETARD/ROLLOUT)** |
| 조종석 | **3D 가상 조종석**(기종별 여객기 플라이트덱/GA/전투기/헬기/글라이더, 실시간 계기 텍스처, 움직이는 요크·사이드스틱·추력레버·플랩레버) 또는 2D 계기판. PFD/ND/ECAM·EICAS, G1000 PFD/MFD+EIS, 6팩 아날로그, 헬기 계기, TE 바리오, 전투기 정합 HUD |
| 외장 | 실제 치수 기반 절차적 3D 기체 + **리버리**(하우스 컬러 및 항공사 스타일: 동체 타이틀·창문·치트라인·꼬리 도안·등록부호) |
| 제원 | 기종별 제원표(초도비행·승무원/좌석·엔진·치수·중량·속도·상승한도·항속·FDM 계수) + 행거 3D 미리보기 |
| 커리어 | 학생 → PPL → CPL → 부기장 → 기장 → 시험 조종사. 임무 게시판(관광·화물·여객·전세·의료후송), 착륙 강하율·G·과속·실속 평가, 수입/XP/수리비, 로그북 |
| 기타 | 실시간 METAR, 체크리스트, GPWS·고도 콜아웃 음성, 엔진/바람/경고음 합성, 조이스틱·요크·페달 축 할당, 시점 5종, 시뮬레이션 배속 |

## 조작 (기본)

`↑/↓` 피치 · `←/→` 롤 · `Q/E` 러더 · `F1–F4` 스로틀(F2 유지 = 역추력) · `F5–F8` 플랩 · `G` 기어 · `/` 스포일러 ·
`.` 브레이크 · `Ctrl+.` 파킹 브레이크 · `Ctrl+E` 엔진 시동 · `Z` AP · `Shift+R` A/THR · `Shift+A` APPR · `V` 시점 ·
마우스 오른쪽 드래그 시선 · `P` 일시정지 · `Esc` 메뉴 · `H` 전체 도움말

## 한계

- 상용 MSFS의 Bing 포토그래메트리·수작업 공항 모델·라이선스 기체 모델은 포함할 수 없습니다. 대신 공개 데이터(위성영상·SRTM·OurAirports)와 Google/Bing 스트리밍 옵션을 씁니다.
- 기체 외형·조종석은 실제 치수에서 절차적으로 생성한 모델이며, 리버리는 실제 항공사 도장을 단순화한 *스타일*입니다.
