# SF2027 ⚽

브라우저에서 돌아가는 3D 축구 게임입니다. FC 시리즈처럼 화면 속 경기 시간은 **90분**이고, 실제로 플레이하는 시간은 **12분**(전·후반 각 6분)입니다.

- **킥오프** — 13개 리그 208개 클럽 가운데 두 팀을 골라 바로 한 판. 난이도는 5단계이고, 야간·주간 경기와 CPU끼리의 관전, 게임패드 2개로 하는 로컬 2인 대전을 지원합니다.
- **감독 커리어** — 클럽을 맡아 홈·원정 리그 시즌을 치릅니다. 선발 명단과 포메이션(7종), 전 세계 이적시장(영입·판매), 리그 순위, 득점·도움 순위, 유스 승격, 선수 성장과 은퇴, 시즌 상금까지 들어 있습니다.
- **선수 커리어** — 선수를 직접 만들어 그 선수만 조작합니다(동료에게 **J**로 패스 요청). 경기 평점으로 경험치를 쌓고, 스킬 포인트로 능력치를 올리고, 시즌 평점이 좋으면 이적 제안을 받습니다.
- **온라인** — 계정만 있으면 실시간 1:1 대전을 할 수 있습니다. 빠른 매칭, 코드로 들어가는 친선방, Elo 레이팅과 랭킹이 있습니다. 경기는 서버가 직접 계산하고(Socket.io), Render에 배포하도록 구성했습니다.
- **계정** — 회원가입과 로그인(scrypt 비밀번호 해시, 서명 토큰)을 지원합니다. 커리어는 클라우드에 저장되고, 게스트는 브라우저에 저장됩니다.

## 조작법

| 키 | 공격 | 수비 |
|---|---|---|
| WASD / 방향키 | 이동 | 이동 |
| Shift | 스프린트 | 스프린트 |
| J | 패스 | 태클 (누르고 있으면 압박) |
| K | 슛 (길게 = 파워) | 슬라이딩 태클 |
| L | 스루패스 | 동료 압박 |
| I | 로빙 패스 / 크로스 | — |
| E + K | 감아차기 (피네스 슛) | — |
| F | 개인기 (페인트) | — |
| Q | — | 선수 변경 |
| C / Esc / Space | 카메라 전환 / 일시정지 / 리플레이 스킵 | |

게임패드(Xbox/PS 표준 배치)도 지원합니다. A 패스, B 슛, Y 스루패스, X 로빙, LB 선수 변경, RB 피네스, RT 스프린트입니다.

## 로컬 실행

```bash
npm install
npm start            # http://localhost:3000
npm test             # 엔진 헤드리스 테스트 (CPU끼리 90분 경기)
node test/online.test.js   # 계정·저장·매칭·온라인 경기 E2E 테스트
```

`DATABASE_URL`이 없으면 계정과 저장 데이터는 `./data/db.json`(JSON 파일)에 기록됩니다.

## Render 배포 (온라인 서버)

1. 이 저장소를 GitHub에 푸시합니다.
2. Render 대시보드에서 **New → Blueprint**를 누르고 이 저장소를 선택합니다.
3. `render.yaml`에 적힌 대로 두 가지가 자동으로 만들어집니다.
   - 웹 서비스 `sf2027`: `npm start`로 게임 클라이언트, REST API, Socket.io 온라인 서버를 함께 실행
   - PostgreSQL `sf2027-db`: 계정, 커리어 저장, 랭킹 보관 (`DATABASE_URL`이 자동으로 연결됨)
   - `JWT_SECRET`은 Render가 무작위 값으로 만들어 줍니다.
4. 배포가 끝나면 `https://<서비스이름>.onrender.com`에 접속합니다.

> Render 무료 플랜 참고 사항
> - 웹 서비스는 한동안 요청이 없으면 잠들고, 첫 접속 때 깨어나기까지 수십 초가 걸립니다.
> - 무료 PostgreSQL에는 사용 기간 제한이 있습니다. 계속 운영하려면 유료 플랜으로 올리거나 다른 Postgres의 `DATABASE_URL`을 넣으세요.
> - DB 없이 배포하면 파일 저장소를 쓰는데, 무료 플랜 디스크는 재시작할 때 지워집니다.

## 구조

```
server/        Express + Socket.io 서버 (계정/저장 API, 매칭, 서버 권한 경기 루프)
shared/        브라우저와 서버가 함께 쓰는 코드
  sim.js       경기 엔진: 공 물리(항력, 회전 커브, 바운드, 골대), 선수 AI, 규칙(오프사이드, 파울, 카드, 세트피스)
  squad.js     스쿼드 생성, 능력치, 포메이션, 선발 선택
  career.js    리그 일정, 순위, 시뮬레이션, 성장
  data/        리그·클럽·선수 데이터
public/        게임 클라이언트 (Three.js)
  js/game/     렌더러, 경기장, 선수 모델·애니메이션, HUD, 입력, 사운드, 경기 진행
  js/ui/       메뉴, 킥오프, 감독/선수 커리어, 온라인 로비
```

그래픽은 전부 코드로 만듭니다. 외부 에셋 파일은 없습니다.
- 4K 잔디 텍스처: 줄무늬 잔디 결과 실제 규격 라인
- 2층 스탠드와 인스턴싱한 관중 약 3만 7천 명(골이 들어가면 들썩임)
- 지붕 투광 조명, 움직이는 LED 광고판, 흔들리는 골망
- 관절이 있는 선수 모델: 달리기, 킥, 슬라이딩, 키퍼 다이빙, 세리머니 애니메이션
- ACES 톤매핑과 실시간 그림자
- 카메라: 방송·근접·선수 시점, 골 장면 리플레이

## 데이터 관련 안내

- 클럽 이름과 대표 선수 이름·포지션·능력치는 2025-26 시즌 무렵의 공개 정보를 바탕으로 작성한 **팬메이드 추정치**입니다. 공식 라이선스 데이터가 아닙니다.
- 각 클럽에 등록한 실제 선수 외의 나머지 스쿼드(25명까지)는 국적에 맞는 이름으로 **자동 생성한 가상 선수**입니다.
- 공식 엠블럼, 로고, 유니폼 디자인은 쓰지 않았습니다. 클럽 색상과 약칭으로만 표현합니다. 광고판의 브랜드도 모두 가상입니다.
